# 구몬학습 태블릿 프로토타입 (전시 체험용)

명지대학교 디자인 과제 — 구몬학습 브랜드 경험 개선. Figma 디자인을 그대로 옮긴 iPad 가로 화면(1133×744) 웹 프로토타입입니다.

**체험 주소:** https://saeueon.github.io/kumon/

## 화면 흐름
iPad 홈 → 스플래시 → 홈(성장 대시보드) → 스케줄(11월 1·2·3주차) / 교재 / 마이페이지 → 내 정보 수정 → 수업 입장 로딩 → 1:1 화상 수업 → 나가기 → 홈

화상 수업에서 되는 것
- 판서: 펜·형광펜·지우개·도형·직선·텍스트·메모·색상, 실행 취소/다시 실행
- AI 캐릭터: AI 버튼 → 캐릭터 등장, 캐릭터를 누르면 듣기 → 답변
- 화상 패널: 비디오/채팅/교재 탭, 마이크·카메라·손들기, 패널 접기(좌우 연동), 수업 타이머 00:00부터
- 채팅: 실제 한글 입력, 보내면 선생님 자동 답장

## 화면이 깨지지 않는 이유
모든 화면을 Figma와 같은 1133×744 고정 캔버스로 만들고 기기 화면에 맞춰 통째로 확대·축소합니다. 비율이 다른 기기에서는 위아래(또는 좌우)에 여백만 생기고 배치는 그대로입니다.

## GitHub Pages에 올리기
1. GitHub에서 새 저장소 만들기 (예: `kumon-prototype`, **Public**)
2. 저장소 첫 화면의 **uploading an existing file** → 이 폴더 안의 파일과 폴더를 모두 끌어다 놓기 → Commit
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/kumon-prototype/` 에서 열림

## iPad 전시 세팅
1. Safari로 주소 열기 → 공유 버튼 → **홈 화면에 추가** (주소창 없이 전체 화면으로 실행)
2. 홈 화면 아이콘으로 한 번 실행해 두면 파일이 기기에 저장되어 와이파이가 끊겨도 동작
3. 설정 → 디스플레이 및 밝기 → 자동 잠금 **안 함**
4. 설정 → 손쉬운 사용 → **사용법 유도 접근(Guided Access)** 켜기 → 앱 실행 후 측면 버튼 세 번 → 다른 앱으로 못 나가게 고정
5. 150초 동안 아무도 만지지 않으면 자동으로 처음(iPad 홈) 화면으로 돌아가고 판서·채팅이 초기화됩니다

바로가기: 주소 끝에 `#video`를 붙이면 화상 수업 화면부터 시작합니다.
